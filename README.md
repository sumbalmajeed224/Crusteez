# Crusteez concept site

A single-file concept website for Crusteez: motion-led hero with their real donut photos, a 3D scroll story, a featured-products carousel, the full menu with filters and search, a box builder, and an events and footer section.

## Open it

Open `index.html` in a browser. It needs an internet connection: fonts, the 3D and animation libraries (three.js, GSAP) and the product photos load from the web.

## Notes

- Colours: Burnt Brick `#C84204`, Soft Saffron `#FCEB8E`, Cocoa `#643314`, Warm Ivory `#FDF6F1`.
- Product photos and prices are loaded from crusteez.pk; order buttons link to order.crusteez.pk.
- Ordering, locations, blog and loyalty sign-up are not rebuilt. They link to the existing site.
- Design proposal only. Not an official Crusteez site.
